COMPLETE WORKFLOW (11 STEPS)
================================================================================

1. Upload floor plan PDF (any of 6 available test PDFs)
   → Backend renders first page at 2x zoom

2. Set scale calibration
   → Click 2 points on floor plan, enter real distance (e.g., 5 meters)
   → System calculates pixels/meter

3. Select legend area on floor plan
   → Drag rectangle to define legend region
   → Shows preview of selection

4. Select hatch pattern sample in legend
   → Enter component name (e.g., "Concrete Slab")
   → Drag within legend to select hatch pattern
   → Save hatch sample (backend crops and stores)

5. Run automatic detection
   → Adjust threshold slider (0.3-0.95)
   → Click "Auto Detect"
   → Backend runs OpenCV algorithm on floor plan

6. Review detected regions
   → Panel shows all detected regions
   → Accept/Reject/Delete each region
   → Counts update dynamically
   → Click "Confirm Selection"

7. Add correction polygons (optional)
   → Click "Add Polygon" mode
   → Draw polygon where hatch was missed
   → Click to set vertices, double-click to complete
   → Area calculated in m² using scale

8. Subtract correction polygons (optional)
   → Click "Subtract Polygon" mode
   → Draw polygon to remove from area
   → Double-click to complete
   → Area calculated in m² using scale

9. Upload & set section height
   → Upload side view showing height dimension
   → Crop to height area (drag to select)
   → Manually enter confirmed height in meters
   → Click "Confirm Height"

10. Calculate volume
    → Volume = (detected_area + added_area - subtracted_area) × height
    → Click "Calculate Volume"
    → Result displayed in table

11. Export Excel report
    → Click "Export Excel"
    → Browser downloads "massiq_quantity_report.xlsx"
    → File contains: Project info + Detection stats + Final volume
